## Brand & Style

This design system draws direct inspiration from bespoke mechanical keyboard engineering, tactile instrumentation consoles, and high-precision industrial hardware. Designed specifically for an interactive engineering and technical design portfolio, it bridges physical craftsmanship with high-performance digital ergonomics.

The visual language rejects generic flat design in favor of hyper-tactile skeuomorphic micro-affordances: machined aluminum bezels, dual-tone injection-molded keycaps, smoked semi-translucent polycarbonate housing, and recessed chassis mountings. The atmosphere is nocturnal, focused, and industrial—evoking high-end workshop benches, audio synthesizer interfaces, and mechanical CAD environments.

Key interaction signatures include mechanical switch actuation physics (spring resistance, defined tactile bump, and bottom-out travel states), subtle specular edge bevels, and technical OLED segment readouts that reward tactile curiosity.

## Colors

The palette is anchored in an abyssal deep-space hierarchy: deep carbon canvas (`#030303`), structural chassis panels (`#090909`), and elevated surface wells (`#151515`). Structural boundaries utilize raw machined aluminum tones ranging from deep anodized metal (`#343434`) to milled edge highlights (`#B8B8B8` and `#E2E8F0`).

Functional accent colors mirror vintage and custom mechanical keycap production runs (e.g., PBT double-shot injection palettes):
- **Industrial Orange (`#FF6A00`)**: Primary interactive triggers, active switch states, and critical portfolio actions.
- **Cyber Yellow (`#F7C52B`)**: Cautionary states, interactive hardware toggles, and live execution indicators.
- **Classic Cream (`#F3E6CB`)**: Vintage keycap body surfaces, primary contrast glyphs, and off-white physical labels.
- **Terminal Dark Green (`#245B40`)**: Status displays, verified builds, and hardware PCB accents.
- **Neon Lime (`#A8E94B`)**: Real-time telemetry, active ping markers, and illuminated OLED readouts.
- **Industrial Crimson (`#B43D35`)**: Kill switches, reset triggers, and structural anchor keys.
- **Cyber Pink (`#E98BAF`)**: Secondary function layers and modifier accents.

Micro-borders must consistently use hairline alpha layers (`rgba(255, 255, 255, 0.08)`) to mimic the laser-etched tolerance gaps between mechanical components.

## Typography

The typographic hierarchy implements three distinct roles:
1. **Space Grotesk (Mechanical Structural Headers)**: Engineered display forms with brutalist curves and geometric balance. Used for prominent identity titling, project showcases, and main panel headings.
2. **Inter (High-Fidelity Interface Body)**: Neutral, hyper-legible prose rendering without geometric distraction, ensuring portfolio narrative and technical case studies read effortlessly across all pixel densities.
3. **JetBrains Mono (Technical Telemetry & Key Legend Labels)**: Fixed-width precision used for hardware status indicators, parameter tags, hotkey indicators, coordinates, and OLED readouts. All mono labels should be uppercase with slightly extended letter-spacing to emulate injection-molded legends and industrial laser engravings.

## Layout & Spacing

The layout is built upon an architectural chassis grid model. Instead of borderless floating layouts, the workspace conforms to modular structural bays—replicating aluminum keyboard top-plates, gasket mounts, and switch socket matrices.

- **Desktop (12 Columns)**: Max container width of 1440px with 64px (`margin-desktop`) outer frame padding and 24px (`gutter`) bays. Sections are housed inside distinct structural plates separated by `space-xl`.
- **Tablet (8 Columns)**: Fluid scaling with 32px margins and 16px gutters. Modular plates collapse from side-by-side matrices into vertical sub-assemblies.
- **Mobile (4 Columns)**: 16px (`margin-mobile`) exterior padding and 16px (`gutter-sm`) gaps. Mechanical button clusters convert into scrollable horizontal switch-strips with tactile swipe snapping.

Internal component rhythm adheres to strict 4px base increments, maintaining rigorous alignment between bezel outlines, legend labels, and switch travel heights.

## Elevation & Depth

Visual depth does not rely on ambient diffused cloud shadows; it is rendered through physical mechanics, directional illumination, and multi-layered hardware tiers.

### The Substrate Hierarchy
1. **Floor / Base Case (`#030303`)**: Recessed infinite background, non-interactive base plane.
2. **Chassis Well / Backplate (`#090909` to `#151515`)**: Milled aluminum and dark polycarbonate plates, defined by an inset top highlight (`inset 0 1px 0 rgba(255,255,255,0.06)`) and hairline perimeter (`1px solid rgba(255,255,255,0.08)`).
3. **Smoked Acrylic Layers**: `background: rgba(18, 18, 18, 0.75)`, combined with `backdrop-filter: blur(16px)` and specular rim highlights (`inset 0 0 0 1px rgba(255,255,255,0.12)`).

### Tactile Keycap Physics
Elevated mechanical interactive surfaces (keycaps, toggle switches, project cards) use physically structured multi-stop box shadows:
- **Resting State (Unpressed Keycap)**:
  `box-shadow: 0 4px 0 #000000, 0 6px 12px rgba(0, 0, 0, 0.6), inset 0 1px 0 rgba(255, 255, 255, 0.25), inset 0 -2px 0 rgba(0, 0, 0, 0.4);`
  `transform: translateY(0);`
- **Active / Pressed State (Bottom-Out)**:
  `box-shadow: 0 1px 0 #000000, 0 2px 4px rgba(0, 0, 0, 0.4), inset 0 1px 0 rgba(255, 255, 255, 0.1), inset 0 -1px 0 rgba(0, 0, 0, 0.6);`
  `transform: translateY(3px);`
- **Gasket Mounting Vibration**: Hovering introduces a micro-lift (`translateY(-1px)`) with heightened edge luminance on the top bevel.

## Shapes

The design system employs controlled, tight curvature (`roundedness: 1`). Radii replicate the CNC-milled corners of machined metal bezels and injection-molded keycaps:
- Base standard radius: `0.25rem` (4px) for small interactive keys, input wells, and parameter tags.
- Large container radius: `0.5rem` (8px) for modular chassis panels, hero displays, and structural preview plates.
- Outer housing corner radius: `0.75rem` (12px) for primary peripheral frames and floating diagnostic docks.

Elements must never be fully circular or pill-shaped, except for miniature round LED indicator lenses (`rounded-full` strictly when width equals height <= 8px).

## Components

### Mechanical Keycap Buttons
- **Primary (Industrial Orange)**: Base fill `#FF6A00`, label `#030303` (heavy Space Grotesk or JetBrains Mono), crisp top inner bevel (`inset 0 1px 0 rgba(255,255,255,0.4)`), physical bottom extrusion shadow (`0 4px 0 #9E4200`). On `:active`, physically depresses 3px with mechanical snap timing (`cubic-bezier(0.2, 0.8, 0.2, 1)` in 70ms).
- **Secondary (Brushed Aluminum / Carbon)**: Base fill `#1E1E1E`, hairline perimeter `rgba(255,255,255,0.12)`, label `#E2E8F0`, deep base extrusion shadow (`0 4px 0 #0D0D0D`). Hover triggers subtle brushed silver highlight shimmer.
- **Modifier Keys (Cyber Yellow / Industrial Crimson)**: Reserved for navigation anchors, mode toggling, and interactive filters.

### Interactive Spec Chips & Hotkey Badges
- Compact tags designed as physical keyboard switches with tiny sub-legends. Top-left shows function code (e.g., `FN+1`), center shows label in `JetBrains Mono` (`label-mono-sm`).
- Border: `1px solid rgba(255,255,255,0.08)`, background `#0E0E0E`. Hovering illuminates a tiny 4px status LED embedded inside the chip bezel with `#A8E94B` or `#FF6A00` glow.

### Mechanical Switches (Toggles) & Radio Inputs
- Built as physical toggle switches or heavy rocker keys.
- Well background is recessed (`#050505` with `inset 0 2px 4px rgba(0,0,0,0.8)`).
- Handle/Slider features realistic cross-knurl or horizontal tactile grip ridges. Active state engages a vivid backlit LED glow beneath the thumb-toggle using `#A8E94B` (Neon Lime).

### Technical Input Fields (Terminal Inputs)
- Recessed black enclosure (`#080808`), inset top-shadow emulating an embedded OLED display cavity.
- Monospace typing font (`JetBrains Mono`), blinking mechanical terminal cursor block in `#FF6A00`.
- Outer border transition shifts from dormant brushed steel (`#343434`) to focused laser-orange (`#FF6A00`) accompanied by an ambient subtle luminescence (`0 0 12px rgba(255,106,0,0.2)`).

### Portfolio Project Chassis Cards
- Encapsulated like modular PCB plug-in cassettes.
- Header contains hardware serial number, date stamp, and status telemetry in `label-mono-sm`.
- Card body uses smoked acrylic (`rgba(21, 21, 21, 0.85)`) over subtle vector trace gridlines.
- Interactive card actions are styled as physical keycaps housed along the bottom rim of the module.

### OLED Telemetry Panels
- High-contrast black glass screens with green (`#A8E94B`) or amber (`#F7C52B`) dot-matrix typography.
- Subdued scanline texture overlay (`rgba(0,0,0,0.3)` repeated 2px horizontal bands) to complete the tactile hardware reality.
